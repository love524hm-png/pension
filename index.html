💾 데이터 저장 안내
입력한 모든 정보는 이 기기의 브라우저에만 저장됩니다. 서버로 보내지 않기 때문에 안전한 대신, 만든 사람도 복구해 드릴 수 없어요.

다음 경우에 데이터가 사라집니다 — 기기를 바꾸거나 잃었을 때, 브라우저 데이터를 삭제했을 때, 시크릿 모드로 열었을 때, 아이폰 사파리에서 7일 이상 앱을 열지 않았을 때(홈 화면에 추가하면 예방됩니다).

그래서 설정 탭의 JSON 내보내기로 가끔 백업해 두세요. 저장한 파일은 메일이나 클라우드에도 한 부 두시는 걸 권합니다.
1 처음 시작하는 법
⚙️
설정 탭 → 종목 추가
IRP / 연금저축 각 계좌별로 종목을 추가하세요. 종목명, 종목코드(6자리), 수량, 매입평단가, 목표비중을 입력합니다.
📋
엑셀/구글시트 복사 붙여넣기
'일괄 입력' 버튼을 누르면 스프레드시트에서 복사한 데이터를 한 번에 붙여 넣을 수 있어요. 여러 종목을 한 번에 입력할 때 편리합니다.
↻
시세 갱신 버튼
상단의 '🐻 시세' 버튼을 누르면 네이버 금융 API로 현재가를 자동으로 가져옵니다. 조회 안 되는 종목은 설정 탭 수동 입력을 이용하세요.
2 각 탭 설명
📊
대시보드
전체 평가금액, 수익률, IRP·연금저축 각각 현황, 종목별 현재 비중을 한눈에 볼 수 있습니다.
💼
포트폴리오
종목별 현재가, 손익, 현재비중(파란막대) vs 목표비중(금색선)을 비교합니다. 항목을 탭하면 수정할 수 있습니다.
⚖️
리밸런싱
이달 추가 불입액을 입력하면 목표비중에 맞게 각 종목을 몇 주 매수·매도할지 자동으로 계산합니다. 불입액 없이 0원 입력도 가능합니다.
⚙️
설정
IRP / 연금저축 계좌별 종목 추가·편집·삭제, 월 불입액 설정, 현재가 수동 입력, 데이터 백업·복원을 할 수 있습니다.
3 리밸런싱 계산 방법
🧮
계산 공식
목표 금액 = (현재 평가금액 + 불입액) × 목표비중%
매수 = 목표금액 > 현재금액 (빨간 +N주)
매도 = 목표금액 < 현재금액 (파란 -N주)
500원 미만 차이는 '유지'로 처리
앱 껐다 켜면 데이터 사라지나요?
앱을 껐다 켜는 것만으로는 사라지지 않습니다. 다만 데이터가 이 기기에만 있어서, 기기를 바꾸거나 잃으면 함께 사라집니다. 브라우저 데이터 삭제, 시크릿 모드, 아이폰 사파리에서 7일 이상 미접속도 같은 결과가 됩니다.
서버에 사본이 없으므로 복구해 드릴 방법이 없습니다. 설정 탭에서 JSON으로 꼭 백업해 두세요.
시세가 안 불러와져요
네이버 금융 API를 사용하는데, 네트워크 환경에 따라 실패할 수 있습니다. 설정 탭 → '현재가 수동 입력'으로 직접 입력할 수 있습니다.
목표비중 합계가 100%가 아니어도 되나요?
됩니다. 합계가 100%가 아닌 경우 자동으로 비율에 맞게 정규화하여 계산합니다. 단, 리밸런싱 탭에서 ⚠️ 표시가 나타납니다.
